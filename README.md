# Freedom Broker · Conversation Quality Analytics (CQA)

> Промышленная интеллектуальная система аудита качества клиентских диалогов для Freedom Broker на базе **OpenAI GPT-OSS-120B (Groq)** и резервного **Google Gemini 3.8 Flash**, адаптированная для встраивания в **Microsoft Dynamics 365**, с визуальными шахматными бейджами качества и строгим соблюдением корпоративного дизайна **High-Density CRM**.

---

## 🚀 Основные возможности

### Контур 1 · Оценка и динамический чек-лист
- **Чек-лист из 8 критериев Freedom Broker**:
  - `01 Установление контакта` (10 баллов, ДА/НЕТ)
  - `02 Выявление потребности` (15 баллов, ДА/НЕТ/NA)
  - `03 Идентификация` (20 баллов, ДА/НЕТ/NA)
  - `04 Корректная и полная консультация` (20 баллов, шкала 20/15/10/5/0, NA)
  - `05 Эмпатия и клиентоориентированность` (15 баллов, ДА/НЕТ)
  - `06 Управление диалогом, скорость и грамотность` (15 баллов, шкала 10/7/4/0)
  - `07 Завершение` (5 баллов, ДА/НЕТ/NA)
  - `08 Грубые ошибки` (флаг: оскорбление, предложение в обход компании, утечка конфиденциальных данных)
- **Точный перерасчет весов при N/A**: динамическое пропорциональное перераспределение весов между применимыми критериями с сохранением максимальной суммы 100.00 баллов и округлением до 2 знаков.
- **Мультиязычность**: нативная поддержка диалогов на русском (RU), казахском (KZ) и английском (EN) языках.
- **Интерактивные цитаты**: переход из карточки критерия прямо к конкретной фразе в транскрипте с визуальной анимацией подсвечивания (`Перейти ↵`).
- **Поддержка звонков (Voice Call)**: управление прослушиванием и прямая ссылка на запись в Power Automate / Dynamics 365.
- **Динамический редактор чек-листа**: настройка критериев, весов и шкал «на лету» без перезапуска сервера.

### Контур 2 · Апелляция и пересмотр
- **Подача апелляции**: оператор может оспорить любой критерий, предложив свой балл и указав комментарий с подтверждающей репликой.
- **Кабинет супервизора**: централизованное рассмотрение спорных оценок, принятие решений («Одобрить» / «Отклонить») с фиксацией комментария проверяющего.
- **Мгновенный автоматический пересчет**: при удовлетворении апелляции итоговый балл диалога и секций пересчитывается автоматически с учетом N/A формулы.
- **Аудит-лог**: фиксация каждого действия системы.

## 🛠 Технологический стек

- **Backend**: Python 3.11, FastAPI, Uvicorn, SQLite3, Pydantic, Requests
- **AI Engine**: `openai/gpt-oss-120b` через высокоскоростной API Groq (задержка ~100–300 мс) + fallback на `gemini-3.8-flash`
- **Frontend**: Чистый HTML5 / CSS3 / JavaScript (ES6+), Tailwind CSS, FontAwesome
- **Дизайн-система**: High-Density Financial CRM (глубокий изумруд `#0c3b2e`, акцент `#00965e`, графит `#0f172a`, четкие границы `#cbd5e1`)
- **Интеграция**: Dynamics 365 Web Resource Adapter (`static/d365_adapter.js`) для встраивания в форму или дашборд CRM через iframe.

## 💻 Быстрый запуск

### 1. Установка зависимостей
```bash
python3 -m pip install -r requirements.txt
```

### 2. Настройка переменных окружения
Файл `.env`:
```env
GROQ_API_KEY=your_groq_api_key_here
GROQ_MODEL=openai/gpt-oss-120b
GEMINI_API_KEY=your_gemini_api_key_here
PORT=8000
```

### 3. Запуск веб-сервера
```bash
python3 -m backend.app
```
Откройте браузер по адресу: **`http://localhost:8000`**

## 📖 Руководство оператора и супервизора (Регламент работы)

### 1. Мониторинг и аудит диалогов
- В левой колонке представлен список обращений с высокой плотностью данных (ID, язык, тип канала, сниппет первого вопроса клиента, шахматный статус и итоговый балл).
- Поиск поддерживает фильтрацию по ID диалога или фрагментам текста клиента.
- Доступна быстрая фильтрация по языкам (RU, KZ, EN), типам каналов (текстовый чат / аудиозвонок) и статусам обработки.

### 2. Анализ оценки и работа с доказательствами
- При выборе обращения в центральной области открывается сводная карточка с общим шахматным рейтингом (Brilliant, Great, Good, Inaccuracy, Mistake, Miss, Blunder).
- По каждому из 8 критериев в монолитном блоке отображаются:
  - Точный пересчитанный балл с учетом перераспределения весов N/A.
  - Обоснование оценки от AI-аудитора.
  - Точная цитата оператора с таймкодом (клик на блок цитаты плавно прокручивает транскрипт и подсвечивает реплику).
- Для аудиозвонков доступна прямая интеграция с записью разговора в Power Automate / Dynamics 365.

### 3. Регламент подачи и рассмотрения апелляций
- **Оператор**: если сотрудник не согласен с оценкой по критерию, он нажимает кнопку «Оспорить», указывает запрашиваемый балл и аргументирует позицию с указанием конкретной реплики.
- **Супервизор**: в верхней панели отображается кнопка «Супервизор» со счетчиком ожидающих апелляций. В модальном окне супервизор сопоставляет аргументы сторон, вводит резолюцию и нажимает «Одобрить» или «Отклонить».
- При одобрении система мгновенно выполняет автоматический математический пересчет итогового балла и обновляет статус карточки.

### 4. Управление конфигурацией чек-листа
- Через кнопку «Чек-лист» руководитель группы контроля качества может изменить формулировку любого правила, отрегулировать веса критериев, настроить шкалы или добавить новый корпоративный стандарт обслуживания. Изменения сохраняются и сразу применяются при последующих оценках.
